# Наблюдение за тестом grid-бота

Панель для наблюдения за тестовой торговлей на **ненастоящие деньги**.
Цена биткоина настоящая, берётся с биржи Binance. Сделки виртуальные —
никакие деньги не списываются и не зарабатываются.

Здесь лежит только страница наблюдения и снимок состояния.
Код торговой методики в этот репозиторий не выкладывается.
